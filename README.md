# API Hub Website

A responsive API discovery website built with plain HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- Search API cards by name, category, or description
- Filter APIs by category
- Links to official API documentation
- No build tools or dependencies required

## Run locally
1. Extract `API-Hub-Website.zip`.
2. Open the `index.html` file in your browser.
3. To edit the project, open the folder in VS Code or another code editor.

## Project files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — API data, search, and category filters

## Note
This is a frontend directory/demo. It links to third-party API documentation; it does not provide a backend or proxy requests.
